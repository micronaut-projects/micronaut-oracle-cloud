The `micronaut-oraclecloud-function-client` module lets you invoke Oracle Cloud Functions from a Micronaut application with `@FunctionClient`.

Add the following dependency:

dependency:io.micronaut.oraclecloud:micronaut-oraclecloud-function-client[]

Define one or more configured OCI functions under `oci.functions`.
The map key is the logical name used by `@FunctionClient`.

[configuration]
----
oci:
  functions:
    list-books:
      function-id: ocid1.fnfunc.oc1..example
      fn-intent: Httprequest
      fn-invoke-type: Sync
----

Then create a function client interface:

[source,java]
----
import io.micronaut.function.client.FunctionClient;
import io.micronaut.http.annotation.Body;

@FunctionClient
interface BooksClient {
    Book listBooks(@Body BookRequest request);
}
----

By default, the method name is hyphenated to resolve the configured function name.
You can use `@jakarta.inject.Named` on a method to invoke a differently named function definition.

The request body is serialized to JSON and sent with `InvokeFunctionRequest`.
The response stream is decoded as JSON to the method return type.
Reactive return types are supported when Micronaut can convert from a Reactive Streams `Publisher`.
