Oracle Cloud Autonomous Database connection information and credentials are stored in an https://docs.oracle.com/en-us/iaas/Content/Database/Tasks/adbconnecting.htm[Oracle Wallet].

Micronaut can automatically generate and download the Wallet and configure the data source.

First, you need the correct version of the Oracle Database driver and required modules.
To ensure you are using the correct version, apply the 21.1.0.0 or above Oracle Database BOM with Gradle:

[source,groovy]
----
implementation platform("com.oracle.database.jdbc:ojdbc-bom:21.1.0.0")
----

Or with Maven:

[source,xml]
----
  <dependencyManagement>
    <dependencies>
      <dependency>
        <groupId>com.oracle.database.jdbc</groupId>
        <artifactId>ojdbc-bom</artifactId>
        <version>21.1.0.0</version>
        <type>pom</type>
        <scope>import</scope>
      </dependency>
    </dependencies>
  </dependencyManagement>
----

Second, add a dependency on the `micronaut-oraclecloud-atp` module:

dependency:io.micronaut.oraclecloud:micronaut-oraclecloud-atp[scope="runtime"]

Then configure the <<authentication, authentication provider>>.

Then, add a dependency to one of the Micronaut connection pool implementations.

NOTE: Automated configuration is currently supported only for the HikariCP and UCP connection pool.

dependency:micronaut-jdbc-ucp[groupId="io.micronaut.sql", scope="runtime"]

Or:

dependency:micronaut-jdbc-hikari[groupId="io.micronaut.sql", scope="runtime"]

NOTE: Note that `micronaut-oraclecloud-atp` module is compatible with Java 21+.

To use automated data source configuration from the Wallet, provide a configuration similar to the following:

[configuration]
----
datasources:
  default:
    ocid: ocid1.autonomousdatabase.oc1.....
    walletPassword: micronaut.1
    username: foo
    password: bar
----
- `ocid` specifies the Autonomous Database id
- `wallet-password` encrypts the keys inside the wallet. It must be at least eight characters long, include at least one letter, and either one numeric character or one special character)
- specify the database `username` and `password`
- optionally `service-alias-suffix` controls the suffix used when computing the default service alias using database name and given service alias suffix; defaults to `high` (e.g., set to `tp`)

NOTE: The `username` and `password` are not automatically generated and must be created in advance.

The module uses `(db_name + "_" + service-alias-suffix)` as the default service alias. By default, `service-alias-suffix` is `high`. You can override it (for example to `tp`). If `service-alias` is set, it takes precedence over the suffix-based value.

The wallet is of type `SINGLE`.
Use the `walletType` property to configure different types.
See other valid options at https://docs.oracle.com/en-us/iaas/api/#/en/database/20160918/datatypes/GenerateAutonomousDatabaseWalletDetails[].

TIP: See the guide for https://guides.micronaut.io/latest/micronaut-oracle-autonomous-db.html[Access an Oracle Autonomous Database] to learn more.

==== Token-based (IAM) authentication (optional)

By default, Micronaut uses the wallet and database username/password to authenticate to ADB. Optionally, you can enable token-based authentication (IAM) while still using the wallet for TCPS and service alias resolution.

NOTE: This module does not ship a token provider. You must supply an `IamDbTokenProvider` bean that returns the correct Oracle JDBC token-based authentication properties for your OJDBC version and tenancy/Identity Domain configuration. The OJDBC version must support token-based authentication for Autonomous Database.

To enable IAM mode, configure:

[configuration]
----
datasources:
  default:
    ocid: ocid1.autonomousdatabase.oc1.....
    walletPassword: micronaut.1
    oraclecloud:
      atp:
        auth: IAM
        iamProviderQualifier: iamTest # optional; name of the provider bean to use
----

- `auth` can be `PASSWORD` (default) or `IAM`.
- `iamProviderQualifier` is optional and allows selecting a specific provider bean by name if multiple are present.

Implement a provider by exposing a bean implementing `io.micronaut.oraclecloud.atp.jdbc.iam.IamDbTokenProvider`:

[source,java]
----
import io.micronaut.context.annotation.Requires;
import io.micronaut.context.annotation.Singleton;
import io.micronaut.inject.qualifiers.Qualifiers;
import io.micronaut.oraclecloud.atp.jdbc.iam.IamDbTokenProvider;

import java.util.Properties;

@Singleton
@jakarta.inject.Named("iamTest")
@Requires(env = "oraclecloud")
class ExampleIamDbTokenProvider implements IamDbTokenProvider {
    @Override
    public Properties tokenConnectionProperties(String dataSourceName, String serviceAlias) {
        Properties props = new Properties();
        // Populate with the proper OJDBC token authentication properties/credential object for your setup.
        // For example (property keys vary by OJDBC version):
        // props.setProperty("oracle.jdbc.token", "<ACCESS_TOKEN>");
        // props.setProperty("oracle.net.authentication_services", "(TCPS)");
        return props;
    }
}
----

Behavior:
- PASSWORD mode (default): wallet + username/password (unchanged).
- IAM mode: wallet still configures TCPS and JDBC URL; the password is not used. The token provider's properties are applied to the DataSource/Pool to enable token-based authentication.
- A wallet is still required for secure connectivity and service alias resolution.
